# 领域资料

联盟机构分别管理本地医疗数据；协作控制信息只涉及机构身份、执行许可、数据摘要及回执。

`contracts/entities.json` 保存外部数据的首批交换字段。来源编号仅表示提交方对同一记录的识别符，示例文件不包含真实个人资料。运行时持久化文件由 `DATABASE_PATH` 决定；时间字段使用带时区偏移的 ISO 8601 字符串。

## 跨机构术语与用途协议

护理指标与病种术语在各机构表述不一致，即使患者数据留在本地，名称相同而定义不同的指标也可能被错误比较。本服务为此提供术语与用途的协议登记，边界如下：

- **中心不接收原始病历，也不执行模型训练。** 机构只提交本地字段定义的不可逆摘要（SHA-256 十六进制），以及适用语言、单位与授权用途；中心无法还原原始定义文本。
- **双边确认后生效。** 映射关系的每个版本须由两侧机构的临床负责人分别确认才生效；任一侧否决即失效，可修订后重新提议。
- **生效后方可发放。** 只有存在生效版本的映射才能进入指标目录，目录发放到指定协作任务后不可更改。
- **推翻不删历史。** 术语翻译被推翻时新增版本，旧版本转为 superseded 并保留全部签署记录；使用过旧版本的历史目录与结果保持可查，查询时标注取代关系。
- **最小可见。** 合作方只能查询本机构参与的协作任务下获授权的映射与歧义说明；术语提交仅提交机构、映射对侧机构与监管人员可见。
- **监管可追溯。** 监管人员可沿一个已发布指标（`catalog_id/indicator_key`）找到参与机构的签署记录、术语撤回范围，以及该版本是否已被新版本取代。

撤回是留痕操作：机构撤回术语时须说明撤回范围，撤回后的术语不能用于新映射，但不影响已生效的版本与已发放的目录。

角色通过请求头声明为骨架实现（`X-Institution-Ref`、`X-Actor-Ref`、`X-Actor-Role`），取值见 `contracts/entities.json`；生产部署时应替换为可验证的凭证。完整交互示例见 `fixtures/terminology-flow.json`。
